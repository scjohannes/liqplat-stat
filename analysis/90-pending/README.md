# Pending outcomes

The outcomes in this directory are intentionally non-executing placeholders.
They are not estimable from the current locked public schemas.  Each status
file records the minimum future fields needed before an analysis can be
specified; current aggregate fields must not be used as substitutes.

| Outcome | Status |
| --- | --- |
| Weekly time under treatment | Blocked: no mutually exclusive planned-no-treatment/treatment/death state |
| Time to next treatment line | Blocked: no approved line-transition and observation-completeness contract |
| Time to treatment switch/stop | Blocked: no event type/reason and censoring contract |
| Targeted therapy | Blocked: no qualifying exposure definition and dates |
| Trial referral/recruitment | Blocked: referral is not the same as recruitment/enrolment |
| Physical function | Blocked: instrument, score direction, schedule, and death handling are unspecified |
